<h1 align="center">Software Discovery Engine</h1>

### :information_source: About
The **Software Discovery Engine** is a tool I've architected and engineered to help businesses find software that solves everyday problems or empowers company initiatives.

Built using a React, TypeScript, Vite, Tailwind CSS, and shadcn/ui framework. 

The Software Disccovery Engine is imbued with a wealth of knowledge I've accumulated over the last decade working in the SaaS world. Like UX/UI design, software development, and aligning customer needs with technical solutions.
